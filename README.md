# Mini Projet JEE 2025-2026

## Description

Ce projet est réalisé dans le cadre du module JEE.

L'objectif est de développer une application web de gestion des articles, des paniers et des commandes avec authentification et sécurité.

## Fonctionnalités principales

- Authentification simple avec login et mot de passe
- Gestion des utilisateurs dans une base de données MySQL
- CRUD des articles
- Recherche multicritère des articles
- Gestion du panier
- Validation du panier en commande
- CRUD des commandes
- Modification du statut d'une commande
- Filtres de sécurité
- Architecture en couches : Présentation, Service, DAO
